# ABB Analyze + QUACK v0.8

## New developer actions

- Double-click a Finding to open its file and navigate to its line.
- Double-click an Affected File to open it.
- Suggested Tests provides Open, Copy and safe Run actions.
- Only `dotnet test`, `pytest`, and `python -m pytest` commands without shell metacharacters are executable.
- Test output appears in the Test Results tab.
- Cancel stops QUACK analysis or test execution while preserving the previous review.
- Copy Summary creates Markdown suitable for a PR description.
- Machine statuses are displayed as friendly labels.

See `START-HERE.md` in the bundle root for full setup instructions.
